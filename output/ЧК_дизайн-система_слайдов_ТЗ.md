# ЧК · Дизайн-система презентации — ТЗ для продолжения работы

Действующая колода: https://claude.ai/artifact/6VCEE15FE6mvic1hUw2j8v (5 слайдов, 16:9, 1920×1080).
Это ТЗ описывает систему, по которой она собрана, — для любого дизайнера или Claude-сессии, которая будет делать следующие слайды. Контент берётся ТОЛЬКО из документа «ЧК_архетипы_развития_2026-09-25.docx» и книги «ЧК_олигопрофильные_анализ_2026-09-24.xlsx»; ни одна цифра не придумывается.

## Команда и роли
- **Арт-директор (консалтинговый стандарт)** — держит правило «один слайд = один вывод», принимает/отклоняет каждый слайд. Право вето на слайд без action-заголовка.
- **Слайд-дизайнер** — сетка, типографика, карточки, пилюли; собирает по шаблонам ниже, не изобретает новые.
- **Информационный дизайнер (dataviz)** — все графики; работает по методу: форма ← задача данных, цвет назначается последним, палитра прогоняется через валидатор; никаких двух осей, никаких радуг.
- **Редактор** — язык инвестора: заголовок = вывод целиком, без «инопланетного»; проверяет, что каждый тезис читается без спикера.
- **Фактчекер** — каждая цифра сверяется с листом книги/документом; источник указан в подвале слайда.

## Голос слайда (главное правило)
Заголовок — **action title**: законченный вывод, а не тема. «Рынок не умеет удерживать пациента — маршрут возвращает LTV без CAPEX», а не «Модель 1: описание». Кикер над заголовком — навигация (модель · роль в лестнице). Один слайд — один вывод; всё, что не работает на вывод, уходит в заметки спикера.

## Типографика
- Единый шрифт: **Montserrat** (400/500/600/700), заголовки — 600 (решение заказчика 25.09: Source Serif 4 / IBM Plex Sans заменены — у зрителя часть символов, включая ₽, отображалась квадратиками; у Montserrat полная кириллица и знак рубля).
- Шкала: 72 (титул) / 46 (action title) / 25 (подзаголовки блоков, жирные) / 24–26 (текст) / 24 (подвал, номер). Ничего меньше 24 px.
- Эмфаза весом и цветом, не новыми размерами.

## Палитра
- Тёмный «клиника»: #12333B (титульные/statement-слайды), панель #1C444E.
- Бумага: #F8F7F3 (контентные слайды), карточка #FFFFFF, рамка #E2E0D8, чернила #16323A, текст #43555C, приглушённый #8A9499.
- Цвет = модель, всегда с текстовой меткой (М1/М2/М3), никогда не «цвет сам по себе»:
  - **М1 тил #0E7C7B** (тинт #E3F0EF, тёмный текст #0E5B5A)
  - **М2 слива #8A4067** (тинт #F3E7EE, текст #6E3252; светлый шаг для контекстных баров #B487A2)
  - **М3 нави #1F4E79** (тинт #E6EDF5, текст #1F3A56)
- Предупреждения: янтарь #9C6712 на #FFF6E8 (рамка #E8D5B0). Серый контекст в графиках: #A7B0AB.
- Запрет: модельные цвета не ставить рядом как метки данных в одном графике (нави↔слива не разделимы при protan-CVD); один график = один модельный цвет + серый контекст.

## Сетка слайда
- Поля 128 px; контентные слайды: padding 88/128/150; подвал — закреплённая строка на y≈1016: слева источник, справа номер «N / 5».
- Шапка: кикер (24, ВЕРХНИЙ РЕГИСТР, letter-spacing 2px, цвет модели) → action title (46).
- Тело: две колонки (exhibit слева ~800–840 px, смысл справа) ЛИБО полосный конвейер во всю ширину.
- Низ: 1–2 вывод-карточки (белые, рамка) или лента пилюль на тинте.

## Компоненты (переиспользовать, не изобретать)
- **KPI-плитка**: белая карточка, цифра 38–42 жирным цветом модели, подпись 24 серым.
- **Бар-график**: строка = метка (280–300 px) + бар (h 26, скругление 0 4 4 0 только на конце) + значение жирным чернилами. Главные бары — цвет модели, контекст — серый/светлый шаг. Подпись-легенда одной строкой под графиком. Значения подписаны всегда (текстом, не цветом).
- **Конвейер/воронка**: карточки на тинте с border-top 4 px цвета модели + стрелки x-shape; финальный шаг — залит цветом модели, текст светлый.
- **Пилюли**: белые, текст цвета модели, радиус 20.
- **Предупреждение**: янтарная карточка, начинается с жирного тезиса.
- **Заметки спикера** — в каждом слайде: аргументация, оговорки, ответ на «почему».

## Что запрещено
Заголовки-темы; цифры без источника в подвале; two-axis графики; цвет без текстовой метки; текст <24 px; breakage-цифры в P&L; любые значения не из книги/документа; «примерно» и диапазоны без статуса.
